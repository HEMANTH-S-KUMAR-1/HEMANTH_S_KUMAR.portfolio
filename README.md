# Hemanth S Kumar — Portfolio Website

A clean, modern, single-page portfolio website designed for technical roles in Core Engineering, QA, and IT Support.

## Features
- **Dual-Track Role Toggle**: A unique toggle in the hero section that dynamically switches the candidate positioning (hero subtitle, "About" summary, and resume download link) between two tracks: "Core Engineering & QA" and "IT Support & Systems".
- **Minimalist Design**: Dark navy palette with teal accents, utilizing `Inter` typography.
- **Zero Dependencies**: Pure HTML, CSS, and vanilla JavaScript. No external libraries, no frameworks, no build steps.
- **Mobile-First Responsive**: Looks great on everything from mobile phones to ultrawide desktop monitors.
- **Micro-Animations**: Uses `IntersectionObserver` for performant, scroll-triggered fade-in animations.

## Repository Structure
- `index.html` — The main document with all content semantic structure.
- `style.css` — The complete design system and responsive styling.
- `script.js` — Handles interactivity: the navigation toggle, role-track switching, and scroll animations.
- `assets/` — Contains downloadable resume PDFs (`resume-core-engineering.pdf`, `resume-it-support.pdf`).

## Deployment
This repository is configured to deploy directly to GitHub Pages.
1. Make any updates to `index.html`, `style.css`, or `script.js`.
2. Commit and push your changes to the `main` branch.
3. GitHub Pages will automatically build and deploy the updates.
