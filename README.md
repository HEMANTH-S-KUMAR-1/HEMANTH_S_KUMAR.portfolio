## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties, animations, responsive grid/flexbox layout
- **Vanilla JavaScript** — typed-text animation, canvas particle background, scroll reveal, navbar behaviour
- **Google Fonts** — Inter and Fira Code
- **Font Awesome 6** — icon set

No build tools, bundlers, or frameworks are required. The entire site is a single self-contained `index.html` file.

## Getting Started

No installation or build step is needed. To preview the site locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/HEMANTH-S-KUMAR-1/HEMANTH_S_KUMAR.portfolio.git
   cd HEMANTH_S_KUMAR.portfolio
   ```

2. **Open in a browser**

   Open `index.html` directly in any modern web browser:

   ```bash
   # macOS
   open index.html

   # Linux
   xdg-open index.html

   # Windows
   start index.html
   ```

   Or serve it with any static file server, for example:

   ```bash
   npx serve .
   ```
