## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Dark Glassmorphism Design** | Premium dark UI with cyan/purple accent gradients, blur effects, and card-based layout |
| ⚡ **Zero Build Step** | Pure static HTML — no frameworks, no bundlers, no dependencies to install |
| 📱 **Fully Responsive** | Mobile-first design with hamburger navigation and adaptive grids |
| 🔤 **Typing Animation** | Animated role typewriter effect in the hero section |

## 🛠️ Local Development

No dependencies required — just open the file in a browser:

```bash
# Clone the repository
git clone https://github.com/HEMANTH-S-KUMAR-1/HEMANTH_S_KUMAR.portfolio.git

# Open in browser
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or use a local server for best results:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

## 🎨 Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--bg-color` | `#0a0e1a` | Page background |
| `--card-bg` | `#0f1729` | Card backgrounds |
| `--text-main` | `#ffffff` | Primary text |
| `--text-muted` | `#a0aec0` | Secondary text |
| `--accent-cyan` | `#00d4ff` | Primary accent (CTA, links, highlights) |
| `--accent-purple` | `#7c3aed` | Secondary accent (tags, gradients) |

**Typography:** [Inter](https://fonts.google.com/specimen/Inter) (body) + [Fira Code](https://fonts.google.com/specimen/Fira+Code) (code/tags)

**Icons:** [Font Awesome 6.5](https://fontawesome.com/)
