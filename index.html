Projects

Featured Projects

Real-Time Safety System in Elevator During Power Failure

Problem

Elevators lack real-time occupant detection and emergency communication during power failures, creating significant safety risks in multi-storey buildings.

What I Built

An embedded safety system that detects occupant presence via a load cell, triggers SMS alerts to emergency contacts through a GSM module, and relays failure status wirelessly between elevator and building control units.

Tools & Components

Arduino Nano HX711 Load Cell GSM Module (SIM800L) HC-12 Wireless Transceiver

What It Demonstrates

Sensor integration, real-time embedded systems design, wireless communication protocols, and safety-critical system thinking.

Multichannel Stethograph

Problem

Traditional stethoscopes provide a single-point audio feed with no digital recording, analysis, or multi-channel comparison capability — limiting their use in research and diagnostics.

What I Built

A 4-channel digital stethograph using MEMS microphones connected via I2S to an ESP32, streaming audio data to a Raspberry Pi for real-time signal processing. Built a desktop GUI for visualisation with both time-domain and frequency-domain feature extraction.

Tools & Components

ESP32 INMP441 MEMS Mics Raspberry Pi 4 Python (Librosa, SciPy, Pydub) Tkinter GUI I2S Protocol

What It Demonstrates

Multi-channel sensor data acquisition, I2S protocol implementation, real-time signal processing, and full-stack hardware-to-software integration.
